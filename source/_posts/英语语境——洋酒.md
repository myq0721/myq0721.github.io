# 二、发酵过程（The Fermentation Process）

## How is Alcohol Made?

**Beer is made from fermenting grains.**

**Wine is made from fermenting grapes.**

**Cider is made from fermenting fruits (like apples & pears).**

**Even milk can be fermented to make alcohol...**

> 啤酒由谷物发酵制成；葡萄酒由葡萄发酵制成；苹果酒等由水果（如苹果、梨）发酵制成；甚至牛奶也可发酵成酒。

**要点**


| 表达                              | 含义          |
| ------------------------------- | ----------- |
| made from fermenting grains     | 由谷物发酵制成     |
| made from fermenting grapes     | 由葡萄发酵制成     |
| made from fermenting fruits     | 由水果发酵制成     |
| like apples & pears             | 如苹果、梨等      |
| milk can be fermented           | 牛奶也可发酵      |
| to make alcohol                 | 以制成酒精饮品     |


# 三、蒸馏过程（The Distillation Process）

Fermentation can only take you so far. As soon as the alcohol percentage of a brew hits around **15%**, fermentation is no longer possible. There is either no more sugar left in the brew to ferment or the yeasts themselves drown/die because the alcohol content is too high.

This is where the distillation process comes in.

> 发酵有其上限：当酒液酒精度升至约 15% 时，发酵便难以为继——要么原料中已无糖可发酵，要么酵母因酒精浓度过高而失活。此时便需要蒸馏。

**要点**


| 表达                                              | 含义              |
| ----------------------------------------------- | --------------- |
| can only take you so far                        | 只能走到这一步；有其极限    |
| the alcohol percentage of a brew                | 酒液的酒精百分比        |
| hits around 15%                                 | 升至约 15%         |
| fermentation is no longer possible              | 发酵不再可能进行        |
| no more sugar left in the brew to ferment       | 酒液中已无糖可发酵       |
| the yeasts themselves drown/die                 | 酵母自身失活/死亡       |
| because the alcohol content is too high         | 因酒精浓度过高         |
| This is where the distillation process comes in | 这正是蒸馏工艺发挥作用之处 |


The distillation of fermented products produces distilled beverages with a high alcohol content, or separates other fermentation products of commercial value.

> 对发酵产物进行蒸馏，可得到高酒精度的蒸馏酒，或分离出具有商业价值的其他发酵产物。

**要点**


| 表达                                                      | 含义              |
| ------------------------------------------------------- | --------------- |
| the distillation of fermented products                  | 对发酵产物的蒸馏        |
| distilled beverages with a high alcohol content         | 高酒精度的蒸馏酒        |
| separates other fermentation products                   | 分离其他发酵产物        |
| of commercial value                                     | 具有商业价值的         |


# 四、酒精风味（Alcohol Flavors）

Alcohol doesn't have any flavor of its own. All of its flavors come from the ingredients used to make it (grains, grapes, fruit, etc), and anything else that was added along the way.

> 酒精本身并无风味；所有味道均来自酿造原料（谷物、葡萄、水果等），以及酿造过程中添加的其他成分。

**要点**


| 表达                                      | 含义           |
| --------------------------------------- | ------------ |
| doesn't have any flavor of its own      | 本身并无风味       |
| come from the ingredients used to make it | 来自酿造所用原料     |
| grains, grapes, fruit, etc              | 谷物、葡萄、水果等    |
| anything else that was added along the way | 酿造途中添加的其他成分 |

# 七、六大烈酒（Six Types of Liquor）

All generally sit around the **40% ABV** mark.

> 六大烈酒的酒精度通常在 40% ABV（酒精体积比）左右。

## Vodka（伏特加）

Vodka is defined as a neutral-flavored clear spirit that is generally made from grains (mostly grains) and potatoes. It's meant to be virtually tasteless, odorless and clear in color but, vodka does have subtle flavor profiles that can be distinguished between brands.

Made from grains such as wheat and corn or potatoes.

> 伏特加是一种风味中性、色泽清澈的烈酒，原料多为谷物（以谷物为主）或马铃薯；理论上应几乎无味、无嗅、无色，但不同品牌之间仍可分辨出细微风味差异。常见原料为小麦、玉米等谷物，或马铃薯。

**要点**


| 表达                                      | 含义              |
| --------------------------------------- | --------------- |
| neutral-flavored clear spirit           | 风味中性、色泽清澈的烈酒    |
| made from grains and potatoes           | 由谷物与马铃薯酿制       |
| virtually tasteless, odorless and clear | 几乎无味、无嗅、无色      |
| subtle flavor profiles                  | 细微风味特征          |
| distinguished between brands            | 可在品牌间加以区分       |
| wheat and corn                          | 小麦与玉米           |


**代表品牌**

| Skyy     |             | 深蓝伏特加            | 产地：美国；世界十大伏特加之一 |


## Gin（金酒）

Gin is essentially flavored (but not sweetened) vodka. It's clear in color and flavored with various botanicals and spices. The most important ingredient in gin is the juniper berry. Gin **MUST** be flavored with the juniper berry or it isn't Gin...

Gin is usually made from a base of grain, such as wheat or barley, which is first fermented and then distilled.

It's easy to make your own compound gin from vodka.

> 金酒本质上是加香（但不加糖）的伏特加，色泽清澈，以多种植物香料调味；杜松子是金酒最重要的原料——必须以杜松子调味，否则不能称为金酒。通常以小麦、大麦等谷物为基酒，先发酵再蒸馏。亦可用伏特加自行调配 compound gin（复方金酒）。

**要点**


| 表达                                      | 含义              |
| --------------------------------------- | --------------- |
| flavored (but not sweetened) vodka      | 加香但不加糖的伏特加      |
| botanicals and spices                   | 植物香料            |
| the juniper berry                       | 杜松子（必备原料）       |
| a base of grain                         | 谷物基酒            |
| fermented and then distilled            | 先发酵后蒸馏          |
| compound gin                            | 复方金酒；自行调配的金酒    |
| make your own compound gin from vodka   | 用伏特加自制复方金酒      |


## Whisk(e)y（威士忌）

For whisk(e)y to be whisk(e)y, it must be distilled from fermented grain juice (essentially beer!) and depending on where it's from, it must adhere to strict legal requirements.

Bourbon, Scotch, Irish Whisky, blends, single malts, etc all have certain requirements they need to adhere in order to earn their names.

> 要称为威士忌，须以发酵谷物汁（本质上就是啤酒！）蒸馏而成；因产地不同须遵守严格的法定要求。波本、苏格兰威士忌、爱尔兰威士忌、调和酒、单一麦芽等，各有命名所须满足的条件。

**要点**


| 表达                                      | 含义              |
| --------------------------------------- | --------------- |
| distilled from fermented grain juice    | 由发酵谷物汁蒸馏而成      |
| essentially beer                          | 本质上即啤酒          |
| adhere to strict legal requirements     | 遵守严格法定要求        |
| in order to earn their names            | 方能获得相应名称/称谓     |
| Bourbon, Scotch, Irish Whisky           | 波本、苏格兰、爱尔兰威士忌等  |
| blends, single malts                    | 调和威士忌、单一麦芽等     |


### Five Types of Scotch（苏格兰威士忌五类）

| 类型              | 英文              | 说明                                      |
| --------------- | --------------- | --------------------------------------- |
| 单一麦芽            | single malt     | 单一酒厂、仅用麦芽与水酿制                           |
| 单一谷物            | single grain    | 单一酒厂酿制；除麦芽外可含玉米、小麦等谷物                    |
| 调和麦芽            | blended malt    | 由两家及以上酒厂的单一麦芽调和                         |
| 调和苏格兰威士忌        | blended Scotch  | 单一麦芽与单一谷物（或谷物威士忌）调和                     |
| 调和谷物            | blended grain   | 由两家及以上酒厂的单一谷物威士忌调和                       |


**示意关系**

- 酒厂 A、B（麦芽 + 水）→ 单一麦芽 A、单一麦芽 B → 调和麦芽（A + B）
- 酒厂 C（麦芽 + 玉米 + 水）→ 单一谷物 C；酒厂 D（麦芽 + 小麦 + 水）→ 单一谷物 D
- 单一麦芽 B + 单一谷物 C → 调和苏格兰威士忌（blend）
- 单一谷物 C + 单一谷物 D → 调和谷物


## Rum（朗姆酒）

Rum is distilled from sugar cane or molasses (a thick dark brown juice obtained from raw sugar, most rums are made from molasses). It's often aged in wooden barrels and because it's primarily made in the Caribbean, it's requirement laws are nowhere near as strict as whisk(e)y.

Rum is sometimes flavored with other spices to make 'spiced rums'.

> 朗姆酒以甘蔗或糖蜜（从原糖中获得的浓稠深褐色汁液，多数朗姆酒以糖蜜为原料）蒸馏而成；常于木桶中陈酿。因主产于加勒比地区，其法规要求远不及威士忌严格。亦可加入香料制成 spiced rum（香料朗姆酒）。

**要点**


| 表达                                      | 含义              |
| --------------------------------------- | --------------- |
| distilled from sugar cane or molasses   | 由甘蔗或糖蜜蒸馏而成      |
| a thick dark brown juice                | 浓稠深褐色汁液         |
| obtained from raw sugar                 | 从原糖中获得          |
| aged in wooden barrels                  | 木桶陈酿            |
| primarily made in the Caribbean         | 主产于加勒比地区        |
| nowhere near as strict as whisk(e)y     | 法规远不如威士忌严格      |
| spiced rums                             | 香料朗姆酒           |


## Tequila（龙舌兰）

Tequila is made by distilling fermented blue agave (a plant native to Mexico) juice. And it has quickly become the up and coming spirit in recent years. Once considered a mediocre spirit reserved for shots, the quality of tequila has risen dramatically and the more premium brands are meant to be sipped and savored – similar to single malt Scotch.

> 龙舌兰酒以发酵后的蓝色龙舌兰（墨西哥原产植物）汁液蒸馏而成。近年迅速崛起；曾被视为仅供干杯的平庸烈酒，如今品质大幅提升，高端款宜慢饮细品——类似单一麦芽苏格兰威士忌。

**要点**


| 表达                                      | 含义              |
| --------------------------------------- | --------------- |
| fermented blue agave juice              | 发酵后的蓝色龙舌兰汁      |
| a plant native to Mexico                | 墨西哥原产植物         |
| the up and coming spirit                | 新兴热门烈酒          |
| reserved for shots                      | 仅供干杯（一饮而尽）      |
| the quality has risen dramatically      | 品质大幅提升          |
| meant to be sipped and savored          | 宜慢饮细品           |
| similar to single malt Scotch           | 类似单一麦芽苏格兰威士忌    |


## Brandy（白兰地）

Brandy is made by distilling fermented fruit juice. Technically, any fermented fruits can be made into brandy but the majority of the time, fermented grapes (wines) are used.

Among the most renowned are Cognac and Armagnac from southwestern France.

> 白兰地以发酵果汁蒸馏而成；理论上任何发酵水果均可酿制，但多数以发酵葡萄（葡萄酒）为原料。最著名的包括法国西南部的干邑（Cognac）与雅文邑（Armagnac）。

**要点**


| 表达                                      | 含义              |
| --------------------------------------- | --------------- |
| distilling fermented fruit juice        | 蒸馏发酵果汁          |
| any fermented fruits                    | 任何发酵水果          |
| fermented grapes (wines)                | 发酵葡萄（葡萄酒）       |
| the majority of the time                | 大多数情况下          |
| among the most renowned                 | 最著名的之一          |
| southwestern France                     | 法国西南部           |
